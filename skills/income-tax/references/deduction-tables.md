## 生命保険料控除

### 新制度（平成24年1月以降の契約）

| 支払保険料 | 控除額 |
|-----------|--------|
| 2万円以下 | 全額 |
| 2万超〜4万円 | 支払額/2 + 10,000円 |
| 4万超〜8万円 | 支払額/4 + 20,000円 |
| 8万円超 | 40,000円（上限） |

### 旧制度（平成23年12月以前の契約）

| 支払保険料 | 控除額 |
|-----------|--------|
| 2.5万円以下 | 全額 |
| 2.5万超〜5万円 | 支払額/2 + 12,500円 |
| 5万超〜10万円 | 支払額/4 + 25,000円 |
| 10万円超 | 50,000円（上限） |

- 新旧合算の1区分上限: 40,000円
- 3区分（一般/介護医療/個人年金）合計上限: 120,000円

### 子育て世帯の特例（令和8年分・令和9年分限定、租税特別措置法41条の15の5）

23歳未満の扶養親族がいる場合、新制度の一般生命保険料控除の上限が6万円に拡充される（介護医療・個人年金・合計上限12万・住民税は変更なし）。

| 支払保険料（新制度・一般） | 控除額 |
|-----------|--------|
| 3万円以下 | 全額 |
| 3万超〜6万円 | 支払額/2 + 15,000円 |
| 6万超〜12万円 | 支払額/4 + 30,000円 |
| 12万円超 | 60,000円（上限） |

共働きで子を一方の扶養に入れている場合でも、夫婦双方が特例を適用できる。
